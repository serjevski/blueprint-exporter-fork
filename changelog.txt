Version: 0.4.0
Date: 2026-10-07
  Bugfixes:
    - rebuild-books.ps1: the output JSON now uses the correct Factorio book schema — "blueprints" array with per-entry "index" fields, plus "item", "active_index", and "version" metadata on every nested book. This fixes the empty-book import issue.
    - rebuild-books.ps1: fixed the last byte of the Adler-32 checksum in Compress-Zlib (was $a -shr 8 instead of $a -band 0xFF), which caused zlib decompression failures.
    - rebuild-books.ps1 and json-to-string.ps1: UTF-8 BOM is now stripped when reading exported .json files, preventing invisible control characters from corrupting the output JSON.
    - rebuild-books.ps1: the slot an item held in game is taken from the number the mod prefixes its file and directory name with, instead of being renumbered from zero. A book with a record deleted in the middle keeps the positions it had, and a nested book keeps the slot it occupied in the book above it.
    - rebuild-books.ps1: the prefix is converted per level rather than copied or shifted uniformly. The entries of a book are keyed from one, while the shelves player.blueprints and game.blueprints are keyed from zero, so a shelf now passes its numbers through unchanged and a book gives one up. Shifting both the same way either emptied the first slot of every book or emptied the first slot of a shelf, and in both cases every following entry landed one place to the right.
    - rebuild-books.ps1: passing several roots to -In no longer lets two of them claim the same slot. Each shelf numbers its entries from the beginning, so a later shelf is now placed after the last slot the earlier ones took; before, the first entry of the second shelf collided with the first of the first and Factorio dropped one of the two.

Version: 0.3.0
Date: 2026-10-07
  Features:
    - The converters travel inside the mod and are rewritten into script-output/blueprint-exporter/tools/ at the end of every export: json-to-string.ps1 (PowerShell) and json-to-string.sh (bash) turn an edited .json back into an importable blueprint string.
    - The real name of every record survives the export: _export.label and _export.book_path in each .json, and a _book.json sidecar in every book directory. File names only ever lose the rich-text markup.
    - Added tools/rebuild-books.ps1: rebuilds a whole blueprint book from the exported directory tree, so the library (or any part of it) can go back into the game as a single book string. Runs on PowerShell 5.1 and 7 alike.
    - Added tools/clean-orphans.ps1 and tools/clean-orphans.sh: delete the .txt/.json files that a blueprint deleted in game leaves behind under p/ and g/, using manifest.json as the source of truth. The PowerShell version runs on 5.1 and 7; the bash version needs nothing beyond bash and coreutils. Both support a dry run (-WhatIf / --dry-run).
  Changes:
    - The mod is renamed to "Blueprint Exporter Fork" (internal name blueprint-exporter-fork) and now conflicts with the original blueprint-exporter mod.
    - File and directory names are fitted to a 140 UTF-16 unit budget; a directory shares what is left with everything below it, so deep book nesting stays within the Windows path limit.
  Bugfixes:
    - Keys in the exported .json keep their original case; folding them to lower case corrupted case-sensitive mod data under tags.
    - json-to-string.ps1: fixed handling of a single file passed as -In.
